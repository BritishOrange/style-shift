# StyleShift

Локальный сервис смены стиля текста. Работает на вашем компьютере, использует предобученную модель Qwen2.5-1.5B-Instruct.

## Что нужно

- Python 3.10 или новее
- ~3–4 ГБ свободного места на диске (под зависимости и модель)
- Интернет при первом запуске (скачивание модели с Hugging Face)
- Рекомендуется 8+ ГБ оперативной памяти

## Быстрый старт (Windows)

1. Склонируйте репозиторий:

```bash
git clone <URL_ВАШЕГО_РЕПО>
cd <имя-папки-репо>
```

2. Запустите `start.bat` двойным кликом  
   или в терминале:

```bash
start.bat
```

3. Дождитесь в консоли сообщения `Модель готова.`  
   При первом запуске загрузка модели может занять несколько минут.

4. Откройте в браузере: [http://localhost:3000](http://localhost:3000)

## Запуск вручную (Windows / macOS / Linux)

```bash
git clone <URL_ВАШЕГО_РЕПО>
cd <имя-папки-репо>

python -m venv .venv

# Windows:
.venv\Scripts\activate

# macOS / Linux:
source .venv/bin/activate

pip install -r requirements.txt
python app.py
```

Откройте [http://localhost:3000](http://localhost:3000).

## Как пользоваться

1. Введите текст.
2. Выберите стиль (академический, деловой, неформальный и т.д.).
3. Дождитесь статуса «Модель готова».
4. Нажмите «Перефразировать».

## Важно

- Модель **не входит** в репозиторий: она скачивается автоматически при первом запуске.
- Повторные запуски быстрее — модель берётся из локального кэша Hugging Face.
- Сервис слушает только `localhost` (доступен с вашего компьютера).
- На CPU генерация может занимать несколько секунд.

## Структура

```
app.py              # сервер Flask + запуск модели
requirements.txt    # зависимости Python
start.bat           # быстрый запуск на Windows
public/             # веб-интерфейс
  index.html
  styles.css
  app.js
```
